# Eventura Creations

## Description
This is a portfolio website created for an event planning company to showcase their services, past events, and overall brand presence. The website is designed to present information in a visually appealing and user-friendly way.

## Features
- Display of services offered
- Showcase of past events/projects
- Clean and structured layout
- Easy navigation across sections

## Tech Stack
- HTML
- CSS
- JavaScript

## Purpose
This project was developed to understand how portfolio websites are designed for businesses and to gain hands-on experience in building real-world web interfaces.

## Status
This is a beginner-level project created for learning and practice.
